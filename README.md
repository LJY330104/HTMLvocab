# HTML 词汇复习

一个纯本地、单文件的背单词小工具。双击 `index.html` 就能用，不用装任何东西、不用联网、不用起服务器。

```
HTMLvocab/
├── index.html            ← 双击这个
├── lists/
│   ├── .gitignore        ← 目录里的词书一律不入库
│   └── list13-14.js      ← 本地私用词库（97 词，**不在仓库里**，只在作者硬盘上）
├── dict/
│   ├── ecdict.js         ← 内置英汉词典（77 万词条，约 50MB，点「创建词库」才加载）
│   └── LICENSE-ECDICT    ← ECDICT 的 MIT 许可原文
├── tools/
│   └── build_dict.py     ← 重新生成 dict/ecdict.js 用的脚本
├── LICENSE               ← 本项目的 MIT 许可
└── README.md             ← 就是这份说明
```

---

## 启动时是空的

页面**默认不加载任何词库**——打开是一片空状态，点「选择词书文件」选一个 `.js` 才开始。
这样 `index.html` 跟具体词库完全解耦，换词书不用改 HTML。

> 每次刷新都要重新选一次文件（浏览器不允许网页记住本地文件句柄）。
> 进度不受影响：选同名的词库，之前的记录会自动读回来。

## 怎么用（键位）

| 键 | 什么时候按 | 作用 |
|---|---|---|
| `1` `2` `3` `4` | 没作答时 | 选第 1~4 个释义 |
| `←` | **没作答时** | 不认识 → 直接显示答案，**记为答错** |
| `←` | **答对之后** | 承认是蒙的 → 改判为答错，统计跟着改 |
| `←` | **答错之后** | 手滑了 → 撤销这次判定（统计、插回的那道题一起撤），重答这一题 |
| `→` | 答完之后 | 继续下一题 |
| 空格 / 回车 | 答完之后 | 同 `→`（习惯用哪个都行） |
| `Q` `W` `E` `R` | 选项被折叠时 | 展开/收起第 1~4 个选项（和点选项右边的「⤢ 展开」一样） |
| `5` | 选项被折叠时 | 一次全部展开 |
| `↓` `↓` | 练的时候随时 | **连按两下** → 一键保存进度到词书（等于点「💾 存进度」） |
| `M` | 任何时候 | 切换亮色 / 暗色（等于点右上角 ☀️ / 🌙） |
| `Esc` | 设置面板开着时 | 收起设置面板 |

**每个键都有对应的按钮**（答题区底部那一排），鼠标/触屏玩家不用记键：

| 按钮 | 等于 | 说明 |
|---|---|---|
| 选项本身 | `1`~`4` | 点就直接作答 |
| 👀 不认识 / 🙈 是蒙的 / ↩ 手滑了 | `←` / `F` | 同一个按钮，字会跟着状态变 |
| ⤢ 全部展开 | `5`（单开某个：`Q` `W` `E` `R`，或点选项右边那个 `⤢ 展开`） | 把所有折叠的长选项一次全展开 |
| 💾 存进度 | `↓` `↓` | 中途存一次 |
| ✕ 不练了 | — | 直接结束这一轮，进结算 |

几条规则：

- **答错了会锁一小会儿**（默认 **1.5 秒**，可在右上角 ⚙️ 里拖到 0.5~3.0 秒），
  按钮上会倒数「答错了 · 1.5 秒后可继续」，逼你在解析上多停一会儿再走。
  （这是故意的：错完立刻翻页，等于把刚才那次检索白费了。）
- 答错时，解析里会先显示**你选的那个选项**，并标明它其实是哪个词的意思，比如
  「你选的：v. 使陶醉，使入迷　（其实是 intoxicate 的意思）」，方便做近义辨析。
- 选项文字**左对齐**，序号固定在左侧。
- **超过 40 字的释义会折叠**（从 ECDICT 建的词书常见，比如 `run` 有十几条义项），
  显示前 40 字 + 省略号，**选项右端**有个 `⤢ 展开` 小按钮（和文字分开、靠右对齐）。
  点它、按 `Q`/`W`/`E`/`R` 对应第 1~4 个选项，或者按 `5` 一次全展开。
  作答之后**自动全部展开**，省的你想看正确答案还得再点一次。
- 底部「💾 存进度」按钮和双击 `↓` 是同一件事：**练到一半随手存一次**，不用等这一轮打完。
  存档会把当前这一轮已经答的题算进进度里，之后再打完结算也不会重复累加。
- 答题区下方有**会变的键位提示**：没作答时提示「← 不认识」，答对后提示「← 其实是蒙的 / → 继续」，
  答错后提示「← 手滑了，撤销重答 / → 继续」。
- **按错了不用认**：答错后按 `←` 会把这次判定整体撤回——错的计数、插回队列的那道题、倒计时全部还原，
  选项还是原来那四个（不会重新抽），重新选就行。
- **答对不等于真会了**：答对之后，这个词会在 **10 题后**再出现一次，词头上挂绿标「复查 · 确认会了没」。
  复查答对才算过；复查又答错照样按答错处理。每轮每个词最多复查一次。

## 答题设置（右上角 ⚙️）

点顶栏右边的 ⚙️ 弹出，改完立刻生效，存在 `localStorage['satvocab.quiz.v1']` 里，下次打开还在。

| 设置 | 范围 | 默认 | 说明 |
|---|---|---|---|
| 答错后等待 | 0.5 – 3.0 秒（拖滑杆，0.1 秒一档） | **1.5 秒** | 答错后「继续」按钮锁多久，正在锁着的时候拖会立刻按新时长重算 |
| 「以上都不对」混淆项 | 开 / 关 | **开** | 开的时候每道题的 **D 选项固定是「以上都不对（None of the above）」**，它一定不是正确答案——正确释义只会出现在 A/B/C 里 |
| 出现频率 | 0% – 100%（5% 一档） | **30%** | 每道题有多大概率混进这个干扰项；关掉开关时滑杆变灰 |

关掉混淆项就回到「三个干扰释义 + 一个正确释义」的老样子，正确项在 A~D 里随机。

## 进度存在哪

**两层，逐词取较新的那份：**

1. **浏览器 localStorage**（自动、实时）——键名 `satvocab.v1.<词库id>`
2. **词表文件里**（一键保存，跟着文件走）

### 一键保存（不用复制粘贴）

首页的 **「💾 保存进度」**（右下并排那两个里的左边）和结算页的 **「💾 一键保存进度到词书」** 是同一件事：

- **Chrome / Edge**：弹一次保存对话框，选中 `lists/list13-14.js` 就**直接写回原文件**，真一键
- **Safari / Firefox**：自动下载一个新 `words.js`，改名后拖进 `lists/` 覆盖即可

生成的是**完整词书 + 进度快照**，格式和手写版一致，随时可以继续手改。

### 创建词库（自己录词）

首页 **「✏️ 创建词库」**，进去以后：

1. 输入框里打英文单词，**自动带出音标、词性、中文义项**（数据来自内置的 ECDICT 词典）。
2. 打的是变形也能认：比如输 `perceived` 会提示「是变形，原形是 perceive」。
3. **直接按回车**就加进词表（默认把带出的义项全收）；想挑义项就先勾选，再点「加入词表」。
   同名词会自动覆盖，不会重复。加完输入框自动清空、光标留着，可以接着打下一个。
4. 下面列出已加的词，点 ✕ 删掉；改上面两个框里的 `id` 和标题。
5. 点 **「💾 导出词书 .js」**，存成 `list-new.js` 这种文件，回首页载入即可。
6. 想马上试试就点 **「⚡ 直接载入」**——不过它**不会写文件**，刷新就没了，
   所以点它之前会弹个框提醒你先导出。

详说几点：

- **词典是懒加载的**：`dict/ecdict.js` 那 50MB 只有在你点开「创建词库」时才读，平时不占一点内存。
  载入后会给词典建一次行索引（几十毫秒），之后每次查词 1–4ms。
- **词典里查不到**的词：点「手填释义」或者直接回车，卡片里会出现两个输入框（释义、词性），
  填完回车或点「加入」即可，不用再弹系统对话框。
- 一条义项都没勾就回车，会提示「至少勾一条释义」，并且**不清空输入框**，免得白打。
- 编辑中的词表**存在浏览器里**（`satvocab.build.v1`），刷新页面不丢；导出之后这才算进了文件。
- 换一本词典：页面上「词典没载入 / 想换一本」可以手动选 `dict/ecdict.js`，
  或者直接把 ECDICT 原版 `ecdict.csv` 丢进去也能认。

### 看词表

首页 **「📋 看词表」**：整本词书摊开给你看，每行是「序号 · 单词 · 词性释义 · 练过几次 / ✓对 / ✕错」。
顶部有搜索框（单词和中文都能搜），下面一排统计：练过几个、错过几个、累计对错次数。
只读页面，练到一半想查个词也方便。

### `lists/` 里的词书都不进仓库

`lists/.gitignore` 用的是「全忽略再放行」的写法：

```gitignore
*
!.gitignore
```

意思就是：这个目录里**什么词书都不提交**，只有 `.gitignore` 自己进仓库——
你自己录的词书、导出的 `words.js`、`list13-14 2.js` 这种重复副本，都老老实实待在硬盘上。
哪天想公开一本示例词书，就在那个文件里加一行 `!你的文件名.js`。

### 换词书

首页 **「📂 选择本地词书文件（.js）」**，挑一个格式正确的 `.js` 就会载入（只读本地，不上传）。
多本并存时右上角出现下拉切换。

> Safari 用 `file://` 直接打开时**不允许本地存储**，页面顶部会出现红字警告——那种情况下进度只在本页有效，练完必须立刻一键保存。

页面启动时两边都读，按每个词的 `ts`（更新时间）合并，谁新用谁。所以：

- 改 `index.html`、换电脑、清浏览器记录 → 进度从词表文件里读回来，不丢
- 词表文件里的快照旧了 → 浏览器里的新记录会自动盖过它

每条记录长这样：

```js
"denote": { "seen": 1, "ok": 1, "bad": 0, "ts": 1793310000000 }
// seen = 练过几次，ok / bad = 累计答对、答错次数，ts = 最后更新时间戳
```

> 以前版本的记录里还有 `lvl`（间隔档位）和 `due`（到期时间）两个字段，
> 跨天计划撤掉以后这两个字段不再使用，读到旧记录时会被自动丢掉。

> 彻底重置 = 删掉 `lists/list13-14.js` 末尾那段快照 **并且** 点「清空进度」。
> 只做一样，另一边会把进度读回来。

## 怎么换词库

打开一个词书文件（比如 `lists/list13-14.js`），在 `window.VOCAB_LISTS` 里加一条就行，**不需要改 index.html**：

```js
window.VOCAB_LISTS = {
  "list-01": { title: "...", words: [ ... ] },

  // 新加一条长这样
  "list-02": {
    title: "SAT Word List 02（50 词）",
    words: [
      ["abate", "v.", "减弱，减轻", "abate the storm 风势减弱"],
      ["candid", "adj.", "坦率的；偷拍的", "a candid remark 直言"]
    ]
  }
};
```

每条单词是 4 个字段，顺序不能乱：

| 位 | 内容 | 例 |
|---|---|---|
| 0 | 单词 | `"abate"` |
| 1 | 词性 | `"v."` / `"n."` / `"adj."` / `"n./v."` |
| 2 | 中文释义 | `"减弱，减轻"` |
| 3 | 搭配 / 记忆点 | `"abate the storm 风势减弱"` |

- 词性里的 `v.`、`n.`、`adj.` 会被用来**生成同词性的干扰项**，写全一点效果更好。
- 有多个词库时，页面右上角会出现下拉菜单切换；也可以在网址后面加 `?list=list-02` 直接进某本。
- 每本词库的进度是**分开存**的（按 id 区分），换词库不会互相污染。

> 词库用 `.js` 而不是 `.json` 是故意的：浏览器在 `file://` 下会拦掉 `fetch()` 读本地 JSON，但 `<script>` 不受限。

## 配色（Material You）

- **顶栏 ☀️ / 🌙 按钮**：点一下在亮色、暗色之间切换，选择记在 `satvocab.mode`。
- 从没点过的时候是**跟随系统**（`prefers-color-scheme`）；点过之后就以你的选择为准，
  想回到跟随系统，清掉 `localStorage` 里的 `satvocab.mode` 即可。
- 明暗由 `<html data-mode="light|dark">` 决定，两套色板都写在 `index.html` 开头的 `:root` 里。
  `data-mode` 由一个**放在 `<style>` 前面的小脚本**在首屏渲染前就写好，所以不会先闪一下浅色再变暗。
- **种子色写死 `#4d6bfc`**（蓝色），没有取色面板。改色就直接改那两段 `:root`
  （`--primary` / `--surface` 等），色值是按下面的 tone 表算好的 OKLCH 字面量。

界面是普通的卡片风格：浅色卡片 + 细边框 + 柔和投影，没有拟物凹凸。

色板按 **Material 3 的 tone 规则**从种子色生成，再以 OKLCH 字面量写死：

| 变量 | Material 3 角色 | 亮色 tone | 暗色 tone |
|---|---|---|---|
| `--bg` | background / surface | 97 | 6 |
| `--surface` | surface-container（卡片） | 100 | 13 |
| `--surface-2` | surface-container-high（进度条底、数字徽章） | 93 | 21 |
| `--surface-3` | surface-container-highest（滑杆轨道、开关底） | 89 | 27 |
| `--text` | on-surface | 10 | 92 |
| `--text-2` | on-surface-variant | 30 | 80 |
| `--line` | outline-variant | 80 | 37 |
| `--primary` | primary | 40 | 80 |
| `--primary-c` | on-primary | 100（纯白） | 20 |
| `--primary-soft` | primary-container | 90 | 30 |
| `--good` | 自定义 success | 36 | 80 |
| `--good-soft` | success-container | 90 | 30 |
| `--bad` | error | 40 | 80 |
| `--bad-soft` | error-container | 90 | 30 |

中性色（surface / text / line）都带一点种子色的色相（269.59），彩度按 tone 做钟形收缩，
两端降彩度，所以同一颗种子色在明暗模式下都保持同一个色相，又不会在极端明度上发灰。
成功绿（色相 150）和错误红（色相 25）各用一个固定色相，保证「对/错」的语义不被种子色冲掉。

**刻意偏离规范的地方**（都是为了肉眼能看见）：

- `--line` 暗色用 tone 37，比 M3 的 outline-variant（30）亮一点——1px 细边在小屏上太暗就糊没了。
- 卡片底色在暗色下比背景亮 7 个 tone（13 vs 6），卡片才从背景里浮出来（M3 的 surface 本身不区分这层）。
- success 绿不是 M3 的角色，是按种子色的规则额外生成的。

跑 JS 只为了切换 `data-mode`，不再逐像素重算颜色——首屏因此没有颜色跳变。

## 布局（宽屏 / 横屏）

- **窄屏（手机竖屏）**：单栏，`.wrap` 最大 620px。
- **宽屏（≥1000px）**：`.wrap` 变成两栏——左边 620px 是原来的内容，右边是**看板娘**（大肥鱼本体）。
  右边不抢焦点，只是把多余的横向空间用起来；页面滚到底时她会跟着一起走（`position:sticky`）。
- **横屏 + 矮窗口（高度 ≤560px）**：上下留白收窄、进度条隐藏、单词字号压小，
  **四个选项改成两列**，一屏能看全，不用来回滚。

看板娘是**内嵌的 PNG**（图片以 base64 写在 `index.html` 里，背景已经抠成透明），
不额外加载图片文件，离线也能看。平时站着的是 `assets/mascot.png`，一开始答题就换成
`assets/mascot-quiz.png`（`body.on-quiz` 时切换），答完回到结算页又换回来。
想换图就替换这两个文件再重新内嵌。
她会跟着当前页面换台词：首页、答题、建词库、看词表、结算各一句。

## 复习是怎么安排的

**你问的“错了插到几个之后”——做了，而且是递进的：**

| 同一个词本轮第几次错 | 插回位置 |
|---|---|
| 第 1 次 | 第 4 题之后 |
| 第 2 次 | 第 8 题之后 |
| 第 3 次 | 第 16 题之后 |

（只针对当次会话，保证“趁热打铁”，但又不至于错完立刻又撞上，那样没检索难度。）

**答对也不放过**：答对的词会在 **10 题后**再出现一次，词头挂绿标「复查 · 确认会了没」，
复查答对才算真过。每轮每个词最多复查一次。

**没有跨天的复习计划**：不排「今天到期」「明天该复习」这种日程，也不会在后台算下次什么时候练。
练几轮、什么时候练，全看你自己。页面上只留了几个统计数：

| 首页卡片 | 含义 |
|---|---|
| 还没练过 | 一次都没做过 |
| 练过 | 至少做过一次 |
| 错过 | 至少答错过一次 |

进度存在浏览器的 `localStorage` 里，键名 `satvocab.v1.<词库id>`。**清浏览器数据会一起清掉**，这点要有心理准备。

```bash
python3 tools/build_dict.py ecdict.csv dict/ecdict.js          # 默认
python3 tools/build_dict.py ecdict.csv dict/ecdict.js --full   # 连英文释义一起留下
```

`ecdict.csv` 需要自己从 ECDICT 仓库下（约 63MB），本仓库没有再存一份原版 CSV。

## 为什么这么设计

- **主动回忆 > 重读**：选择题逼你从四个干扰项里挑，比看一遍释义记得牢，哪怕答错也是有效学习。
- **一轮之内就重复 > 事后补课**：错词当场插回、答对再复查一次，靠的是这一轮里的重复，不靠跨天排日程。
- **合意难度**：干扰项专门挑同词性的近义项，太容易反而不长记性。
- **乱序**：每次题目顺序和选项位置都重排，防止记住“答案在第三个”。

一句话：把「答错立刻重来、答对再确认一次」压缩在同一轮里，练完就是练完了，不留作业。
