# HTML 词汇复习

一个纯本地、单文件的背单词小工具。双击 `index.html` 就能用，不用装任何东西、不用联网、不用起服务器。

```
sat-vocab/
├── index.html            ← 双击这个
├── lists/
│   ├── list13-14.js      ← 主词库（SAT Word List 13–14，97 词）
│   └── test.js           ← 测试词表（10 词 · 六年级）
├── wordlist-01.md        ← 当前这批词的完整表格，供通读
└── legacy/               ← 早期两版页面，留着当备选
    ├── wordlist-01-drill.html   认识/不认识 翻卡
    └── wordlist-01-quiz.html    纯四选一，无记忆调度
```

---

## 启动时是空的

页面**默认不加载任何词库**——打开是一片空状态，点「选择词书文件」选一个 `.js` 才开始。
这样 `index.html` 跟具体词库完全解耦，换词书不用改 HTML。

> 每次刷新都要重新选一次文件（浏览器不允许网页记住本地文件句柄）。
> 进度不受影响：选同名的词库，之前的记录会自动读回来。

## 怎么用（键位）

| 键 | 什么时候按 | 作用 |
|---|---|---|
| `1` `2` `3` `4` | 没作答时 | 选第 1~4 个释义 |
| `←` | **没作答时** | 不认识 → 直接显示答案，**记为答错** |
| `←` | **答对之后** | 承认是蒙的 → 改判为答错，统计和间隔都会跟着改 |
| `→` | 答完之后 | 继续下一题 |
| 空格 / 回车 | 答完之后 | 同 `→`（习惯用哪个都行） |

几条规则：

- **答错了会锁 2 秒**，按钮上会倒数「答错了 · 2 秒后可继续」，逼你在解析上多停两秒再走。
  （这是故意的：错完立刻翻页，等于把刚才那次检索白费了。）
- 答错时，解析里会先显示**你选的那个选项**，并标明它其实是哪个词的意思，比如
  「你选的：v. 使陶醉，使入迷　（其实是 intoxicate 的意思）」，方便做近义辨析。
- 选项文字**左对齐**，序号固定在左侧。
- 答题区下方有**会变的键位提示**：没作答时提示「← 不认识」，答对后提示「← 其实是蒙的 / → 继续」。
- **答对不等于真会了**：答对之后，这个词会在 **10 题后**再出现一次，词头上挂绿标「复查 · 确认会了没」。
  复查答对才算过；复查又答错照样按答错处理。每轮每个词最多复查一次。

## 进度存在哪

**两层，逐词取较新的那份：**

1. **浏览器 localStorage**（自动、实时）——键名 `satvocab.v1.<词库id>`
2. **词表文件里**（一键保存，跟着文件走）

### 一键保存（不用复制粘贴）

首页和结算页都有 **「💾 一键保存进度到词书」**：

- **Chrome / Edge**：弹一次保存对话框，选中 `lists/list13-14.js` 就**直接写回原文件**，真一键
- **Safari / Firefox**：自动下载一个新 `words.js`，改名后拖进 `lists/` 覆盖即可

生成的是**完整词书 + 进度快照**，格式和手写版一致，随时可以继续手改。
实在不行还有「复制进度文本」兜底。

### 测试词表（单独文件）

`lists/test.js` 是独立的测试词表，跟正式词库完全分开。
用的时候在首页点 **「📂 选择本地词书文件」**，选它即可（下次打开需要再选一次）。

里面是 borrow / discover / journey / curious 这类六年级词，**专门用来验证功能**：
间隔档位、错词插回、答对复查、一键保存，10 个词一轮几十秒走完，不费脑。
载入后进度单独存在 `satvocab.v1.test` 下，**和 list-01 互不影响**。
这个文件也可以直接当新词书的模板用。

### 换词书

首页 **「📂 选择本地词书文件（.js）」**，挑一个格式正确的 `.js` 就会载入（只读本地，不上传）。
多本并存时右上角出现下拉切换。

> Safari 用 `file://` 直接打开时**不允许本地存储**，页面顶部会出现红字警告——那种情况下进度只在本页有效，练完必须立刻一键保存。

页面启动时两边都读，按每个词的 `ts`（更新时间）合并，谁新用谁。所以：

- 改 `index.html`、换电脑、清浏览器记录 → 进度从词表文件里读回来，不丢
- 词表文件里的快照旧了 → 浏览器里的新记录会自动盖过它

每条记录长这样：

```js
"denote": { "lvl": 1, "due": 1793362102321, "seen": 1, "ok": 1, "bad": 0, "ts": 1793310000000 }
// lvl = 间隔档位，due = 下次到期时间戳，ts = 最后更新时间戳
```

> 彻底重置 = 删掉 `lists/list13-14.js` 末尾那段快照 **并且** 点「清空进度」。
> 只做一样，另一边会把进度读回来。

## 怎么换词库

打开一个词书文件（比如 `lists/list13-14.js`），在 `window.VOCAB_LISTS` 里加一条就行，**不需要改 index.html**：

```js
window.VOCAB_LISTS = {
  "list-01": { title: "...", words: [ ... ] },

  // 新加一条长这样
  "list-02": {
    title: "SAT Word List 02（50 词）",
    words: [
      ["abate", "v.", "减弱，减轻", "abate the storm 风势减弱"],
      ["candid", "adj.", "坦率的；偷拍的", "a candid remark 直言"]
    ]
  }
};
```

每条单词是 4 个字段，顺序不能乱：

| 位 | 内容 | 例 |
|---|---|---|
| 0 | 单词 | `"abate"` |
| 1 | 词性 | `"v."` / `"n."` / `"adj."` / `"n./v."` |
| 2 | 中文释义 | `"减弱，减轻"` |
| 3 | 搭配 / 记忆点 | `"abate the storm 风势减弱"` |

- 词性里的 `v.`、`n.`、`adj.` 会被用来**生成同词性的干扰项**，写全一点效果更好。
- 有多个词库时，页面右上角会出现下拉菜单切换；也可以在网址后面加 `?list=list-02` 直接进某本。
- 每本词库的进度是**分开存**的（按 id 区分），换词库不会互相污染。

> 词库用 `.js` 而不是 `.json` 是故意的：浏览器在 `file://` 下会拦掉 `fetch()` 读本地 JSON，但 `<script>` 不受限。

## 配色（Material You）

右上角 🎨 打开配色面板：

- **选种子色**：点色块或直接输 `#3f6653` 这类色值
- **从图片取色**：选一张图，自动抠出最适合做种子的颜色（排除近白、近黑、纯灰，
  按「出现频率 × 鲜艳度」打分）
- 6 个预设色一键切换

整套界面颜色按 **Material 3 的色调规则**实时生成：

| 角色 | 亮色 tone | 暗色 tone |
|---|---|---|
| primary | 40 | 80 |
| primary-container（`--primary-soft`） | 90 | 30 |
| surface | 99 | 10 |
| background | 96 | 6 |
| on-surface（文字） | 12 | 92 |
| outline（描边） | 84 | 28 |

色板用 **OKLCH** 生成（`tone(L*) → OKLab 亮度`，彩度按 tone 做钟形收缩，两端降彩度），
所以同一颗种子色在明暗模式下都能保持同一个色相，又不会在极端明度上发灰。
成功绿和错误红各用一个固定色相独立生成，保证「对/错」的语义不被种子色冲掉。

配色存在 `localStorage` 的 `satvocab.seed`，刷新后自动恢复。
浏览器不支持 `oklch()`（很老的版本）时自动退回内置默认色。

## 复习是怎么安排的

**你问的“错了插到几个之后”——做了，而且是递进的：**

| 同一个词本轮第几次错 | 插回位置 |
|---|---|
| 第 1 次 | 第 4 题之后 |
| 第 2 次 | 第 8 题之后 |
| 第 3 次 | 第 16 题之后 |

（只针对当次会话，保证“趁热打铁”，但又不至于错完立刻又撞上，那样没检索难度。）

**跨天则走间隔档位**，目标是让遗忘发生在“你要想起它之前”：

档位 0 → 1 天 → 2 天 → 4 天 → 8 天 → 15 天 → 30 天 → 60 天

- 一次答对：档位 +1，下次按新档位隔开
- 答错：档位 −1，退回更近的间隔
- 首页的“已掌握”统计的是档位 ≥ 4 的词（间隔已在 15 天以上）

进度存在浏览器的 `localStorage` 里，键名 `satvocab.v1.<词库id>`。**清浏览器数据会一起清掉**，这点要有心理准备。

## 为什么这么设计

- **主动回忆 > 重读**：选择题逼你从四个干扰项里挑，比看一遍释义记得牢，哪怕答错也是有效学习。
- **间隔 > 集中**：一天刷十遍，不如分成五天各刷一遍。
- **合意难度**：干扰项专门挑同词性的近义项，太容易反而不长记性。
- **乱序**：每次题目顺序和选项位置都重排，防止记住“答案在第三个”。

一句话：当天猛刷只提升“当下熟练度”，跨天的间隔复习才把它推进长期记忆。
